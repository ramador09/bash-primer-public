# Course data

The working dataset for this course is real computational-science output —
`.xyz` trajectories and CP2K / LAMMPS inputs and results — drawn from the
**Molecular and Materials Modelling (MMM)** course (ETH Zürich, FS2023). The
shell commands in the notebooks operate on these files as a *playground*: **you
never need to understand the physics** to do the shell work. Every exercise that
uses a scientific setting says so explicitly and tells you what to ignore.

## Layout

```
data/
├── trajectories/      # .xyz coordinate trajectories
│   ├── lj38-optimization.xyz   # a 186-frame geometry optimisation
│   └── lj38-relaxed.xyz        # the final relaxed 38-atom cluster
├── inputs/            # the run inputs that produced the results
│   ├── geo-opt.inp             # CP2K geometry-optimisation deck
│   ├── production-md.inp       # CP2K molecular-dynamics deck
│   └── replica-exchange.lammps # LAMMPS replica-exchange script
├── results/           # parsed/condensed outputs
│   ├── sn2-neb.ener            # NEB reaction-path energies
│   └── pt-slab.xyz             # a platinum slab geometry
├── logs/              # real CP2K run logs (excerpts) — the grep/awk playground
│   ├── gr2hno3-nvt.log         # a graphene + HNO3 molecular-dynamics run
│   └── gr2hno3-restart.log     # a restart of the same system
├── scaling/           # timing tables — the speedup/efficiency playground (Notebook 17)
│   ├── strong_scaling.csv      # strong scaling (cores -> walltime); synthetic, see scaling/README.md
│   ├── weak_scaling.csv        # weak scaling (constant work per core)
│   └── generate.py             # the generator (Amdahl + seeded noise) + the answer key
└── .dataset-notes     # a hidden file (find it with `ls -a`)
```

This is the tree you navigate from Notebook 2 onward.

## Provenance, licence, privacy

These files come from Raymond Amador's MMM material and are republished with
permission (content CC BY 4.0; see `../LICENSE-CONTENT`). They were passed through
`../tools/scrub.sh`, which removes incidental usernames and internal cluster
hostnames from run files — none were present in this set, but the pass is part of
the course's privacy hygiene (and a later notebook uses the script itself as a
real `sed`/`grep` example).

One exception to "measured output": the `scaling/` tables are **synthetic** —
generated by `scaling/generate.py` from an Amdahl model with light, *seeded*
(reproducible) noise, so the speedup/efficiency exercises in Notebook 17 are
cleanly gradeable. They are framed around a realistic Euler scenario but are not
one specific run's numbers. The schema (`cores,walltime_s`) is deliberately plain
so real anonymized scaling data can replace them later with no notebook changes —
see `scaling/README.md`.
